Descrição
Este projeto foi desenvolvido como atividade da disciplina de Desenvolvimento Web da faculdade. O objetivo é aplicar os conceitos básicos de HTML para criação e estruturação de páginas web.

Tecnologias Utilizadas
HTML5
Estrutura do Projeto

## Funcionalidades - Estrutura básica de uma página HTML. - Utilização de títulos e parágrafos. - Inserção de listas. - Inclusão de links. - Organização semântica do conteúdo. ## Como Executar 1. Baixe ou clone este repositório. 2. Abra o arquivo `index.html` em qualquer navegador. 3. Visualize a página web. ## Objetivos de Aprendizagem - Compreender a estrutura de um documento HTML. - Utilizar as principais tags de marcação. - Desenvolver páginas web simples. - Aplicar boas práticas de organização de código.
